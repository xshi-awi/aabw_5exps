# 提议：my_style 加一条「不用 不是……而是 / 是……而不是」

来源：用户 2026-11-26 在 aabw 回复信 TexPage 批注里写「请不要用“不是。。。。而是”或者“是，，，，而不是。。。”的句式，这个请加入写作铁律。」`~/.claude` 归总管改，这里只放建议的 diff，由总管落进 `~/.claude/skills/my_style/SKILL.md`。

建议插在「可执行规则清单 › 句子与结构」第二条（3 层嵌套从句）之后：

```diff
 【硬】不写 3 层以上嵌套从句。并列对比用单个 while 或 whereas，带结果用单个 `, leading to` 或 `, resulting in`。
 
+【硬】不用「不是 X 而是 Y」「是 X 而不是 Y」一类对立句式（2026-11-26 用户定）。英文里包括 not X but Y、X, not Y、X rather than Y、rather than X, Y、instead of X 作对照用。直接写正面结论；对照确实是论证必需时，拆成两个各自成立的正面短句。not only … but also 和不带对照的普通否定不在此列。中英文稿件、回复信都适用。
+
 【硬】正文不用 bullet。
```
